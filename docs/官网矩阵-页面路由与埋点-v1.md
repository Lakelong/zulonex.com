> 版本：v1.0  
> 日期：2026-07-30  
> 上游需求：[官网矩阵项目需求与 AI Agent 策略](./官网矩阵项目需求与AI-Agent策略-v1.md)  
> 技术架构：[官网矩阵 MVP 技术架构](./官网矩阵-MVP技术架构-v1.md)

## 1. 路由原则

- 独立项目域名；
- URL 使用小写英文 slug 和稳定层级；
- 不把城市放入 Query 参数作为正式索引入口；
- 一个搜索意图对应一个 canonical 页面；
- 筛选、搜索、预览和后台页面默认不索引；
- 城市和门店停用时按业务状态返回更新说明、301、410 或 404；
- 页面内容与 URL、面包屑、结构化数据和 Sitemap 保持一致。

## 3. P1 路由

| 路由 | 页面类型 | 默认索引 | 说明 |
| --- | --- | --- | --- |
| `/events/` | 活动入口 | 是 | 只展示有效活动 |
| `/events/<slug>/` | 活动详情 | 条件 | 过期活动保留有价值总结 |
| `/topics/<slug>/` | 内容主题页 | 条件 | 必须有独立策划，不自动聚合空页 |
| `/authors/<slug>/` | 作者/审核人 | 条件 | 真实身份和资质 |
| `/evidence/<slug>/` | 公开事实说明 | 条件 | 适合可公开的来源和方法 |
| `/locations/<province>/<city>/events/` | 城市活动 | 条件 | 有持续活动才创建 |
| `/locations/<province>/<city>/faq/` | 城市 FAQ | 条件 | 有独立问题集才创建 |

不创建：

- 每个关键词一个页面；
- 每个行政区划自动创建空页；
- 只换城市名的文章副本；
- 无业务承接能力的“附近门店”页；
- 自动生成的对比、排行榜和效果承诺页。

## 7. 页面 SEO 字段

每个可索引页面必须有：

- `title`；
- `description`；
- `h1`；
- `canonical`；
- `robots`；
- `pageType`；
- `audience`；
- `searchIntent`；
- `publishedAt`；
- `updatedAt`；
- `author/reviewer`；
- `structuredData`；
- `sitemapGroup`；
- `indexDecisionId`；
- 使用的 Claim/Evidence。

城市页还必须有：

- `regionId`；
- `serviceStatus`；
- `readinessScore`；
- `lastVerifiedAt`；
- 至少一个真实承接主体。

## 8. 索引门禁

可索引页面必须同时满足：

1. 状态为 `published`；
2. 索引状态为 `indexable`；
3. canonical 唯一；
4. 没有 blocker finding；
5. 必需审批通过；
6. 使用的高风险 Claim 仍有效；
7. 城市/门店未暂停；
8. 页面具有独立价值；
9. 页面未与现有页面形成显著近重复；
10. 页面可从稳定导航或内链访问。

## 9. 用户漏斗

### 9.1 家长体验

```text
搜索/新媒体
  -> 产品/城市/门店页面
  -> 查看机制、案例、FAQ
  -> 选择城市或门店
  -> 提交监护人预约
  -> 正确路由
  -> 门店跟进
  -> 到店/演示
```

### 9.2 机构合作

```text
搜索/招商内容/新媒体
  -> 机构方案
  -> 合作支持、责任和案例
  -> 机构评估表单
  -> 总部或区域负责人
  -> 业务评估
  -> 演示/洽谈
```

两个漏斗使用不同表单和线索类型，不能只通过自由文本判断。

## 10. 埋点原则

- 事件名称使用稳定英文；
- 公共属性统一；
- 服务端记录最终线索成功；
- 客户端事件不能作为成交事实源；
- 不向分析平台发送姓名、电话、表单正文和学生信息；
- UTM 原样保存但限制长度和字符；
- IP 仅用于安全与粗粒度地域，按保留策略处理；
- 事件 Schema 版本化。

## 14. 转化归因

线索保存：

- 首次来源；
- 最近来源；
- 提交页面；
- 页面所属城市；
- 用户选择城市；
- 分配城市/门店；
- UTM；
- referrer；
- campaign/content ID；
- 匿名会话 ID；
- 同意版本。

“来源城市”“用户所在城市”“意向城市”“分配城市”是不同字段，不得混用。

## 15. 页面验收模板

每个页面上线前检查：

- 页面目标和搜索意图明确；
- 核心内容移动端完整；
- CTA 与目标用户一致；
- 标题、描述、H1、canonical 唯一；
- 结构化数据与可见内容一致；
- 所有事实有有效 Claim/Evidence；
- 图片有 alt、尺寸、授权和加载策略；
- 表单有隐私说明、校验、限流和成功状态；
- 分析事件不包含 PII；
- 404、空数据和暂停状态正确；
- 预览与生产版本一致；
- 回滚验证通过。
