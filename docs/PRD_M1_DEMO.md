# M1 本地 Demo 产品需求文档

> 版本：M1 产品架构与实施方案 v0.4（已确认）  
> 更新时间：2026-08-10  
> 适用阶段：M1 本地 Demo  
> 状态：已于 2026-08-10 获用户批准并授权主线实施

## 已确认

### M1 目标

用本地 Demo 以最小闭环验证“总部资源供给—代理商自主创作/复用—总部治理—官网发布”的价值，不建设头条号、小红书级完整平台。v0.4 已确认采用统一后台和两角色视图，主线获准据此实施。

### 核心用户故事

- 作为代理商城市/门店运营主体，我希望像使用朋友圈、小红书或公众号一样创建、排版、预览并送审图文内容。
- 作为总部运营人员，我希望查看图文与 AI 风险提示，进行轻量文字修订，并能退回、通过发布或下架且保留记录。
- 作为总部运营人员，我希望从已确认母版生成多个渠道内容包并下发任务。
- 作为渠道执行人，我希望知道发布到哪里、使用哪份文案和素材，并回填链接、截图或失败原因。
- 作为官网访客，我只能看到总部已确认发布的真实本地内容。

### 页面与路由规划

| 路由 | 页面用途 | M1 关键能力 |
|---|---|---|
| `/` | 合肥公开站入口 | 展示品牌与已发布的合肥本地内容，虚拟信息带 Demo 标识 |
| `/console` | 统一内容协同后台 | 代理商/总部演示角色切换、统一内容与资源模型 |
| `/console/content/new` | 代理商发布编辑器 | 从代理商首页“发布内容”进入，沉浸式完成标题、正文、封面、检查、预览与发布 |
| `/console/content/*` | 内容创作和治理模块 | 编辑、草稿、预览、AI 提示、审核、发布、下架 |
| `/console/resources/*` | 官方资源中心 | 公告、活动、课程、官方内容、优秀实践、素材 |
| `/console/distribution/*` | 轻量渠道分发模块 | 渠道内容包、复制文案、下载素材 |
| `/local/:slug` 或等价演示路由 | 本地内容详情 | 仅展示已确认发布内容 |

`/console` 及其模块路径已确认为 M1 信息架构。v0.3 路由如果保留，只能作为统一后台的兼容跳转，不再构成独立入口。

`/preview` 仅为总部项目管理、研发联调和演示时统一访问各页面的项目全景，不作为代理商后台主页，也不作为对外交付入口。

### 四段 Demo 闭环

#### 1. 代理商创建与送审

代理商在 `/console` 的“发布内容”模块创建图文内容，填写标题、正文、所属城市/服务点、发布时间、联系方式或行动入口；选择封面图并插入、排序、删除图片或添加说明。正文支持段落、一级/二级标题、加粗、有序/无序列表、引用和链接。代理商可保存草稿、进行桌面/移动预览，通过 AI 合规检查后确认并提交审核。图片来自本地上传或演示素材库，M1 不接真实对象存储。

#### 2. 总部审核

总部通过 `/console` 的总部角色视图查看图文、AI 风险提示与建议。总部可轻量修订文字并保留记录；退回时必须填写原因。代理商必须能够修改退回内容并重新提交。总部审核通过后执行公开发布，并可下架已发布内容。

#### 3. 内容分发（P1）

对已确认母版，总部在 `/console/distribution/*` 生成官网、小红书、朋友圈、抖音/短视频说明等渠道内容包；下发的是人工执行任务。执行人回填发布状态、链接、截图或失败原因。

#### 4. 公开展示

确认并设为可公开的内容出现在公开站本地动态、案例或城市内容区域；审核中、退回和仅内部内容不得出现。

### 建议状态模型

`创建内容 → 保存草稿 → AI 合规检查 → 提交审核 → 待总部审核 → 退回修改 → 重新提交 → 审核通过 → 已发布 → 已下架`

AI 检查通过仅代表可以进入总部审核；只有总部审核通过并执行发布后才可公开展示。

### 优先级

**P0**：合肥公开站；代理商图文编辑器、图片插入与基本排版；草稿、预览、AI 检查演示、提交审核；总部审核、退回、重新提交、通过、发布、下架；已发布内容进入公开站；状态和审核记录；全站移除已废止定位。

**P1（P0 稳定后）**：全渠道分发中心演示；基于官网母版生成公众号、小红书、朋友圈、抖音/视频号内容包；发布任务以及链接、截图、数据回传演示；不接真实自动发布 API。

### 总部资源协同（M1-C，P0 已确认）

- 代理商首页及已确认的八项菜单。
- 公告、活动、课程、优秀实践、官方内容、素材的演示资源卡。
- 官方内容库和素材中心演示。
- 总部可上传、启用和停用视频、图片、图文与 PDF 培训资料；代理商可在学习中心按分类和格式查看、播放或阅读。
- M1 上传文件、培训资料状态与学习记录只保存在当前浏览器，不接真实对象存储和生产资源库。
- “直接使用/本地化修改”生成代理商自己的可编辑内容副本，并保留来源关系。
- 资源按访问范围、使用方式和内容形式展示。
- “可直接使用”的资源在原样使用、范围匹配且无需补充本地事实时免重复总部审核；修改、本地化或补充事实后重新送审。

### v0.4 四条验证闭环

1. 代理商自主创作并发布。
2. 代理商复用总部官方内容并形成自己的可编辑副本。
3. 总部退回，代理商修改并重新提交。
4. 官网发布后生成渠道内容包。

### 验收标准

- 代理商可在 3 分钟内完成一条图文创建和送审。
- 正文可基本排版并插入多图，支持桌面端与移动端预览。
- AI 至少标出一类风险并提供建议。
- 总部可退回并说明原因；代理商可修改并重新提交。
- 总部通过后内容出现在合肥公开站，并可下架。
- 全流程显示状态、处理人和处理时间。
- 全站不存在已废止的代理商定位及相关错误文案。
- 虚拟信息明确标注“演示数据，不代表真实运营信息”。
- 页面严格遵循公司官网项目 `design.md`。
- 代理商与总部两个角色视图在统一后台中可完整演示。
- 官方资源直接使用或本地化时保留来源与版本关系。

## 待确认

- 公开站首批展示“动态、案例、城市”中的哪些栏目。

## 当前不做（非范围）

- 云部署、域名解析、生产数据库、真实 CRM。
- 真实账户体系、复杂权限和生产级文件存储。
- SEO 收录、批量城市页和规模化站群能力。
- 社媒 API 自动发帖。
- 传统复杂 CMS、所见即所得页面搭建器。
- 面向代理商展示内容模板；仅预留模板扩展数据结构。
- 真实登录、组织体系、多级区域权限、课程考试/积分/证书。
- 社区、私信、评论、粉丝、排行榜、收益、提现、直播及复杂数据看板。
