# 内容运营与发布规范

> 版本：M1 产品架构与实施方案 v0.4（已确认）  
> 更新时间：2026-08-10  
> 适用阶段：M1 本地 Demo  
> 状态：已于 2026-08-10 获用户批准并授权主线实施

## 已确认

### 角色与术语基线

代理商不是被动提交素材的人，而是其城市/门店内容的运营发布主体；总部负责品牌治理、合规审核和最终公开控制。

统一产品术语：

- `/publish`：代理商内容发布台。
- `/ops`：总部内容运营台。
- `/ops/distribution`：全渠道分发中心。
- 统一状态与动作：创建内容、保存草稿、发布预览、提交审核、待总部审核、退回修改、重新提交、审核通过、已发布、已下架。

v0.4 建议将原分立页面归并到统一内容协同后台；代理商和总部使用同一内容模型，通过角色视图区分。原路径名称保留为 v0.3 历史，不代表 v0.4 的独立产品边界。

### 总部资源供给与复用

总部可以发布公告、活动、课程、官方内容、优秀实践与素材。代理商可以直接使用、下载/复制，或创建本地化可编辑副本后送总部确认。

总部资源同时承担培训资料供给。总部可上传视频、图片、图文和 PDF，设置培训分类、标题、简介和启停状态；已启用资料进入代理商学习中心，停用后代理商不可继续查看。M1 文件、状态和学习记录仅保存在当前浏览器。

每条资源必须记录：

- 访问范围：全部代理商、指定区域、指定代理商、仅总部。
- 使用方式：可直接使用、建议本地化、需要补充事实、仅供学习、已停用。
- 内容形式：图文、图片、视频、附件、渠道内容包。
- 来源资源、来源版本及本地化副本关系。

外地案例不得包装为本地案例；家长反馈必须有授权，学生信息必须去标识化。“优秀实践”可以包含不同内容类型，但伙伴运营案例与家长反馈不能混为同一事实类型。

标记“可直接使用”的官方资源，在原文原素材不变、访问范围匹配且不要求补充本地事实时，可免重复总部审核并直接使用。任何本地化修改、事实补充、联系方式替换、案例地域变更或素材替换，都会生成代理商内容副本并重新进入总部确认链路。

### M1 轻量内容发布体验

代理商端采用类似小红书、微信朋友圈、微信公众号、抖音内容创作的轻量体验，不建设复杂 CMS。必须支持：

- 标题、正文、封面图、图片素材、所属城市/服务点、发布时间、联系方式或行动入口。
- 段落、一级/二级标题、加粗、有序/无序列表、引用和链接。
- 正文插入图片、图片排序/删除/说明、封面选择。
- 桌面端/移动端发布预览、保存草稿。
- 本地上传或从演示素材库选择图片；M1 不接真实对象存储。

### 模板决策

M1 不建设、也不在代理商端展示内容模板。工程与数据结构仅预留 `templateId`、模板类型、字段定义、示例内容、启用状态。动态、服务记录、合作案例、活动预告等模板后续再增加。M1 可以准备不同类型的**内容样本**，但不能把它们定义为代理商端模板。

### 内容治理闭环

1. 代理商自主创建内容，或选择总部资源创建可编辑副本，并保存草稿。
2. AI 执行合规检查，给出风险和修改建议。
3. 代理商确认内容并提交审核。
4. 总部查看图文、AI 风险提示及相关信息。
5. 总部退回时填写原因；代理商修改后重新提交。
6. 总部可进行轻量文字修订并保留记录。
7. 总部审核通过并执行公开发布；已发布内容进入合肥公开站。
8. 总部可以下架已发布内容。
9. P1 阶段从官网可信母版生成渠道内容包并下发人工任务。

### 官网母版与渠道内容包

总部审核通过的官网母版保存完整、已确认事实，是渠道改写的唯一上游。P1 渠道内容包可覆盖公众号、小红书、朋友圈、抖音/视频号，包含标题/首句、正文、推荐图片、话题、发布提示、不得修改的事实、任务负责人及链接/截图/数据回传字段。渠道稿可改变结构和语气，但不得改变确认事实。

### 状态与记录

| 状态 | 责任主体 | 允许动作 |
|---|---|---|
| 草稿 | 代理商 | 编辑、预览、保存、AI 检查 |
| 待总部审核 | 总部 | 查看、轻量修订、退回、审核通过 |
| 退回修改 | 代理商 | 查看原因、修改、重新提交 |
| 审核通过 | 总部 | 公开发布 |
| 已发布 | 总部 | 官网展示、生成渠道内容包、下架 |
| 已下架 | 总部 | 保留历史和下架记录，不再公开 |

全流程必须记录处理人、处理时间、状态变化和必要的修改/退回原因。

## 待确认

- P1 各渠道的固定口吻、字数、图片数量、标签和回传指标。
- 总部审核 SLA、审核人员分工及超时处理规则。
- 正式阶段内容纠错、撤回、下架及渠道同步修订责任人。
- 后续模板启用顺序和模板治理责任人。

## 当前不做

- M1 代理商端内容模板。
- 复杂富文本 CMS、栏目树或页面搭建器。
- 真实对象存储、自动抓取素材和自动调用外部渠道发帖。
- 私信、评论、关注、排名等社区互动。

## 已废止要求

v0.1 中代理商作为被动素材提交者、首批建设并展示四类模板的要求自 2026-08-10 起废止，不再作为开发或验收依据。
